# Smart Hostel Management System

A Java-based web application for hostel administration and student management.

## Features

### Student
- Registration & Login
- Room Details
- Submit Complaints
- Track Complaint Status
- Fee Status
- Notice Board
- Visitor Tracking
- Notifications
- Profile Update

### Admin
- Student Management
- Search Student
- Room Allotment
- Fee Management
- Complaint Resolution
- Notice Posting
- Visitor Management
- Profile Update

## Tech Stack
- Java
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat
- Eclipse IDE

## OOP Concepts Used
- Encapsulation
- Inheritance
- Abstraction
- Method Overriding
